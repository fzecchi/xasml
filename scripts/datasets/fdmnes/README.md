# HDF5 File Layout for Materials Database

This file describes the structure of the HDF5 file generated by `build_materials_database.py`.

## Materials Group Layout

The file is organized with a top-level `materials` group containing individual material entries.

```
materials.h5
├── materials/
│   ├── <material_id>/                     (Group, e.g., "mp-1234")
│   │   ├── structure                      (Dataset, JSON string of pymatgen Structure)
│   │   └── sites/                         (Group)
│   │       └── <index>/                   (Group, site index e.g., "0")
│   │           ├── coordination_environments/ (Group)
│   │           │   ├── fractions          (Dataset, float array[1])
│   │           │   ├── symbols            (Dataset, string array[1], e.g., ["O:6"])
│   │           │   └── csms               (Dataset, float array[1])
│   │           └── spectra/               (Group)
│   │               └── <element>/         (Group, e.g., "Fe")
│   │                   └── <job>/         (Group, e.g., "job15")
│   │                       ├── energies               (Dataset, float array[N])
│   │                       ├── intensities            (Dataset, float array[N])
│   │                       ├── intensities_normalized (Dataset, float array[N])
│   │                       └── intensities_convolved  (Dataset, float array[N])
```

## Key Details

*   **Structure:** Stored once per material (at the material group level) as a JSON string.
*   **Sites:** Identified by their index in the structure.
*   **Spectra:** Nested under `spectra/<element>/<job>` allowing multiple elements and calculation jobs per site.
*   **Coordination Environments:** Contains the analysis results (symbols, fractions, continuous symmetry measures).
