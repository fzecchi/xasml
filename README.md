# X-ray absorption spectra interpretation with machine learning

Code for the analysis of X-ray absorption spectra using random forests and neural networks.

## Installation

```bash
pip install "xasml[data] git+https://gitlab.esrf.fr/spectroscopy/xasml.git"
```

Use `[data,nn]` to also install the packages required by the neural network models.

## Usage

See the `notebooks` and `scripts` folders for usage examples.
